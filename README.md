# PM Desk — ระบบบริหารโครงการส่วนตัว

เว็บแอปสำหรับ Project Manager ใช้งานคนเดียว เป็นไฟล์ `index.html` ไฟล์เดียว ไม่ต้องมี server หรือฐานข้อมูล

## ฟีเจอร์
- **ภาพรวม** — สรุปโครงการที่เปิดอยู่, งานค้าง, งานเกินกำหนด, งานที่ครบกำหนดใน 7 วัน
- **โครงการ** — ความคืบหน้าคำนวณจากงานอัตโนมัติ, สถานะสุขภาพโครงการ (ตามแผน / เสี่ยงล่าช้า / เลยกำหนด), บันทึกประชุม
- **บอร์ดงาน (Kanban)** — ต้องทำ → กำลังทำ → รอตรวจ → เสร็จแล้ว ลากวางได้ ค้นหาและกรองตามโครงการ/ผู้รับผิดชอบ
- **วางแผน (กองงาน + ปฏิทิน)** — พิมพ์งานโยนลงกอง (วางหลายบรรทัดได้) แล้วลากไปวางในวันที่จะทำ มุมมอง 7 วัน / เดือน แยก “วันที่จะทำ” กับ “กำหนดส่ง” งานที่เลยวันที่วางแผนจะเด้งเตือนให้ย้ายมาวันนี้ ใช้ลากได้ทั้งเมาส์และนิ้ว (มือถือลากที่ ⋮⋮ หรือแตะ 📅 เลือกวัน)
- **ไทม์ไลน์** — Gantt ของทุกโครงการ พร้อมเส้นวันนี้และงานด่วน
- **ทีม** — ภาระงานของแต่ละคน
- **รายงาน** — สร้างรายงานความก้าวหน้ารายสัปดาห์/เดือน แยกตามหัวหน้าที่รายงาน คัดลอกไปวางใน LINE/อีเมลได้ทันที
- **ตั้งค่า** — สำรอง/นำเข้าข้อมูลเป็นไฟล์ JSON

## วิธีเอาขึ้น GitHub Pages
1. ไปที่ https://github.com/new → ตั้งชื่อ repo เช่น `pm-desk` → เลือก **Public** → Create repository
2. กด **uploading an existing file** → ลากไฟล์ `index.html` และ `README.md` ใส่ → **Commit changes**
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ https://kittyontheway40.github.io/pm_desk/

## เรื่องข้อมูล
- ซิงก์ออนไลน์ผ่าน **Firebase** (โปรเจกต์ pm-desk-556a0) — ล็อกอินด้วย Google แล้วทุกเครื่องเห็นข้อมูลชุดเดียวกัน
- Firestore rules อนุญาตให้แต่ละบัญชีอ่าน/เขียนเฉพาะเอกสาร `users/{uid}` ของตัวเอง — คนอื่นที่เปิดลิงก์จะไม่เห็นข้อมูลของคุณ
- ยังเก็บสำเนาใน localStorage ด้วย จึงใช้งานออฟไลน์ได้ และซิงก์ต่อเมื่อกลับมาออนไลน์
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย จึงควรสำรองเป็นประจำ (แถบซ้ายจะเตือนว่าสำรองล่าสุดเมื่อไร)
- อัปเดตเวอร์ชันเว็บได้โดยอัปโหลด `index.html` ใหม่ทับ ข้อมูลเดิมไม่หาย
